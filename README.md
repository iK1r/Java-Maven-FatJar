# Java Maven FatJar

Навчальний Java-проєкт, створений у межах домашнього завдання першого модуля курсу GoIT «Системи збирання та управління залежностями».

Мета проєкту — навчитися працювати з Maven, підключати сторонні бібліотеки та створювати виконуваний FatJar-файл.

## Використані технології

- Java 17
- Apache Maven
- Gson 2.15.0
- Maven Shade Plugin
- Checkstyle

## Опис програми

Програма створює JSON-об'єкт, який містить моє ім'я та прізвище англійською мовою, і виводить його в консоль.

Для формування JSON використовується бібліотека Gson, підключена через Maven Central.

**Результат виконання:**

```json
{"name":"Kyrylo","lastName":"Ostashko"}
```

## Збірка проєкту

Для роботи необхідно мати встановлену Java та Maven.

У терміналі, відкритому в кореневій папці проєкту, виконайте:

```bash
mvn clean package
```

Після успішної збірки буде створено виконуваний FatJar-файл:

```text
target/myname.jar
```

Також збірку можна виконати командою:

```bash
mvn package
```

## Запуск програми

Для запуску з кореневої папки проєкту використовуйте команду:

```bash
java -jar target/myname.jar
```

Або перейдіть у папку `target` та виконайте:

```bash
java -jar myname.jar
```

FatJar містить усі необхідні залежності, тому додатково підключати Gson під час запуску не потрібно.

## Перевірка якості коду

У проєкті використовується Checkstyle з конфігурацією `checkstyle.xml` відповідно до рекомендацій ментора.

Для перевірки стилю коду виконайте:

```bash
mvn checkstyle:check
```

Перевірка також виконується під час стандартної збірки Maven.
